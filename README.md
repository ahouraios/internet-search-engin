# پیدا — جست‌وجوی وب

یک نمونهٔ سبک و واکنش‌گرا از رابط جست‌وجوی وب، با رابط فارسی و راست‌چین. جست‌وجوی متنی از MediaWiki API استفاده می‌کند؛ اگر سرویس در دسترس نباشد، چند نتیجهٔ منتخب محلی نمایش داده می‌شود و مسیر ادامهٔ جست‌وجو در وب نیز در دسترس است.

## اجرا

پروژه وابستگی یا مرحلهٔ build ندارد. پوشه را با هر وب‌سرور استاتیکی اجرا کنید؛ برای نمونه:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

سپس `http://localhost:4173` را باز کنید.

## امکانات

- جست‌وجوی زنده با نتیجه‌های ویکی‌پدیا و حالت جایگزین آفلاین
- پیشنهادهای جست‌وجو، جست‌وجو با صفحه‌کلید و میان‌بر `/`
- دسته‌های وب، تصاویر، ویدئو، اخبار و نقشه
- ورودی صوتی در مرورگرهای سازگار با Web Speech API
- پوستهٔ روشن و تیره، طراحی واکنش‌گرا و رابط فارسی راست‌چین
